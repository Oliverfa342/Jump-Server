COMANDOS DE PRUEBAS — JUMP SERVER / FORTIGATE / GNS3
Documentación técnica. Ejecutar en el equipo indicado.

=== R1-ISP (Cisco 7200) ===
enable
terminal length 0
show running-config
show ip interface brief
show ip route

=== SW1 (Cisco IOSvL2) ===
enable
terminal length 0
show running-config
show vlan brief
show interfaces trunk
show interfaces status
show spanning-tree vlan 30
show port-security interface GigabitEthernet0/1

=== USER-PC-1 (Alpine Linux, VLAN 10) ===
ip addr show eth0
ip route
ping -c 4 10.15.71.1
wget -T 5 --no-check-certificate -S -O /dev/null https://10.15.71.130/RDWeb/
# Resultado observado: HTTP/1.1 302 Found y posteriormente HTTP/1.1 200 OK.

# Pruebas de SSH (el fallo no confirma por sí solo que FortiGate lo bloqueó):
